## Requirements

- A C++ compiler such as [g++](https://gcc.gnu.org/) (C++11 or newer)
- Or an IDE such as Code::Blocks, Dev-C++, or Visual Studio

## How to Compile and Run

```bash
# Compile
g++ ATM.cpp -o ATM

# Run (Linux/macOS)
./ATM

# Run (Windows)
ATM.exe
```

Replace `ATM.cpp` / `ATM` with any file in the table above.
